# DeepInfer 相关核心论文

本目录保存两篇与 B21 DeepInfer 直接相关的核心资料。DeepInfer 本身是软件项目；下面两篇分别分析其关键解码机制，以及它所服务的 V4.1-Flash 模型与缓存/部署协同设计，不计入截图论文数量。

| 文件 | 资料 | 收录理由 |
|---|---|---|
| `R01_DSpark_2607.05147.pdf` | *DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation* | DeepInfer 推测解码的核心算法论文。 |
| `R02_DeepSeek_V4.1_Flash_2609.19969.pdf` | *DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression* | V4.1-Flash 的模型架构、KV 缓存压缩与有界重放技术报告。 |

两份 PDF 均从 arXiv 官方页面下载；文件身份、页数和 SHA-256 见同目录 `manifest.json`。
