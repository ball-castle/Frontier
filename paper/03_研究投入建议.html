LORA / RAG / image_generate 等数据清理、切分、训练、检索、前后端及评估工程。作为研究底座。目前可见内容主要是应用实现，需新增可泛化的机制和实验证据才成为方法论文。
SSSP、Centered、Hash、图论与其他数学线精确问题、证明、反例与验证能力。按数学贡献单独管理。与此次 ICML/ECCV 选题的领域契合度不同，不能因此判为低价值，也不必强行包装成 LLM 论文。

上述 ESN 覆盖率来自固定分支的后续执行记录。这已经回应旧评审提出的“缺少分母”；但 UNCERTIFIED 仍表示不确定，不能解释成模型失败或动力学学习必要。仓库里自动评审的分数也不是会议录用概率。

其他关键依据：接口选择分支、真实模型归因结果、最新 GN 笔记、OVS 当前状态、光子 RC 原稿。更详细的本地与远端差异见项目独立复核。

截图透露出的研究兴趣，以及适合迁移的部分

这些论文集中在三个问题：如何用更少资源保存需要的信息，如何把监督或计算投到真正改变结果的位置，以及如何让模型得到可验证的外部反馈。它们与你们已有的状态空间、资源约束、有限程序证书和视觉证据实验相接，比另做一个通用 Agent 或从零训练大模型更适合当前团队。

来源簇值得带走的思想迁移时必须重新验证什么
ReHyAt / RAD / MiTA / LRF-Dyn局部精确处理与全局有限状态结合；把存储和计算形式作为设计变量。语言和延迟事件可能依赖远距离、顺序敏感的信息。视觉的邻近偏置不能自动变成语言的合理归纳偏置。
VISTA / TTME / SEER将观察、执行反馈和成功策略存入外部记忆，固定大部分模型权重。存储是否随历史增长；是否访问了未计费的完整历史；未来任务、样本与技能库是否隔离。
LOWN / PathNavigate / MedFocus / ALD何时需要新证据、证据是否真正支撑答案、何时有资格停止。预测一致不等于答案正确；已有病理取证、充分性核验和风险早停工作需要直接比较。
FSPO / OAR / FORK / HEAPr历史分布监督、结果相关的局部信用、奖励精度、输出空间重要性。把二阶剪枝分数或 token 信用换到另一对象上，不自动带来新贡献。须比较随机/幅值/梯度/短程验证以及相同总训练成本。
Looped Transformers / ELT / Meta Expert复用参数与中间计算，区分参数量、执行深度和内存。共享权重、循环执行、内部蒸馏本身都已有先例；需新的能力–成本规律或明确的失效修复。
Latent-Foresight / FVQ / D4RT / PointCNN++为后续预测、语义或查询设计表示，而非只优化重构或固定表示形式。新领域的瓶颈是否同源；全量模型成本、数据与工程量是否落在团队资源内。

跨领域迁移应迁移“约束下的机制”，而非模块名字。先写出源论文依赖的假设、目标领域违反的假设，再设计修改与对照。拿到新任务最高分只是可能结果；论文价值还需要解释为什么有效、在何处有效，以及成本是否公平。

第一优先验证：同等预算下保留会改变后续决策的状态差异

候选问题：流式系统在未来问题尚未出现时压缩历史。相比保留“显著片段”或“相似度覆盖”，显式保留能区分后续状态的事件差异，能否在相同总存储和计算下，更好地回答顺序、覆盖写入、复位、暂时状态和延迟条件问题？这是待检验的研究假设。

具体例子：同样看到“钥匙在抽屉”和“钥匙被取走”，两段历史的片段集合与画面相似度可能很接近，但顺序决定现在能否在抽屉找到钥匙。重点不是证明简单排序有用，而是判断强记忆系统仍在哪类操作组合上失败，以及一种可扩展保留规则能否修复这些失败。

可尝试的方法骨架：由冻结编码器得到事件候选与置信度；使用低成本状态摘要加少量原始证据槽；在保留或合并时估计删除该记录会合并哪些任务相关的状态；优先保护仍能改变后续答案的区别。对不确定的事件解析保留原始证据，避免过早变成确定事实。最初先用标注事件与同一解析器两种条件，分清解析错误和记忆错误。该骨架的具体学习目标与选择算法仍需查新和试验，不能把本段当作已完成的新方法。

你们的理论积累可以帮助定义任务程序、状态区分与资源账本，但现有 ESN 充分性证书不会直接适用于自然视频或整个 VLM。最有价值的桥梁是一个可被自然任务检验的预测，而不是把线性、有限程序结论扩大为一般大模型定理。

最接近的工作已经做到什么

  • GEM已提出几何冗余不足以保证任务证据保留，并优先保护任务与执行证据。因此“语义优于重构/相似度”不是我们的新发现。
  • MemEvo已经搜索未知未来查询下的有界记忆程序，并核算本地存储；“严格内存预算”本身也不是新贡献。
  • DeltaStreamer已经记录视觉变化并按查询回放，FOLIO已有实体聚焦的语义记忆，MoM已有写时更新与被替代状态的来源历史。

因此余下的工作必须落在：相同可见信息和总资源下，保护具体操作组合中的状态差异，是否比这些强方法有可复现增量。发现相近摘要后仍可研究，前提是明确区别并做直接对照。本轮检索是定向碰撞筛查，不等于已经证实全球新颖性。

第一轮实验应回答的问题

  1. 能否定位失败来源：完整历史能答对 → 压缩记忆答错 → 仅恢复被删的关键证据能修复。三段链条不成立，就不能把错误归因给记忆保留。
  2. 自然任务是否出现：先用可控文本状态程序诊断机制，再用独立选择的自然视频/交互数据验证。视频或场景级切分，标签在看压缩输出前冻结；不按某方法错误来挑测试集。
  3. 强基线是否仍失败：完整历史作参考；均匀、最近、相似度去重作简单基线；MemEvo 及协议适配后的 FOLIO/DeltaStreamer 作流式对照；GEM/MoM 作为跨任务机制参照，GEM 原设置已知当前任务，若适配必须禁止读取未来查询；同一骨干、同一可见前缀与同一查询时刻。
  4. 算力账是否真实：分别计总存储字节、GPU KV/状态、外部帧缓存、预处理、检索/回放次数和端到端延迟。允许保留完整历史的方法应单列存储点，不能作为“免费历史”。
  5. 改进能否复制：第二个模型家族、未见操作组合和更长链条；训练型方法至少三个种子；以视频/任务为单位做配对置信区间。既看整体准确率，也看顺序/当前状态错误与成本曲线。

扩大投入的建议门槛：先证明错误确实来自被丢弃的证据；再在同资源下稳定优于直接前人，或在相同风险下显著减少总成本。可预先选择“关键状态错误相对降低约 20%，整体准确率下降不超过 1 个百分点”作为第一版实用目标，阈值应根据先导误差和样本量调整并在确认实验前冻结。这是投资目标，不是已经观察到的结果。

若已有方法加一点预算便消除优势、只能在合成小例上成立、收益来自免费回放或更强解析器，应停止这个具体方案。若失败定位清楚且出现新机制，延长研究要有新证据依据，不以固定轮数机械停研。

其他候选为什么暂不并行主攻

证据充分性与停止：截图中的 PathNavigate、MedFocus、ALD 可组成很好的阅读路线，但 BEACON已具备竞争假设、信息增益取证和回答/继续/放大控制；REVEAL已有明确充分性核验与针对性重检，CLOSER涉及视觉核验和错误停止；Conformal Thinking已有风险校准早停。把这些组件组合起来不足以作为主创新。只有发现明确未解决的自适应历史条件风险问题，并超过简单置信阈值与已有风险控制，才值得升级。

监督预算与信用分配：FSPO、OAR、FORK 值得第二优先精读，可迁移为“哪些历史教师分布/反馈值得保存”的问题。第一步应比较固定/随机/损失/输出敏感度选择，在相同 rollout、教师计算和总 GPU 小时下是否仍有收益。现阶段它和大量蒸馏、样本选择、RL 信用分配工作相邻，先做文献与复现，不与主线同时铺开。

从零大模型、通用世界模型、再造通用科研 Agent：ZGCM-1、D4RT、Agent Team 等更适合作为设计与实验组织参考。4–8 张 GPU 可以支持小中型开源模型的冻结骨干、轻量微调、蒸馏及多次对照；具体可行性仍取决于显存、序列长度、精度和吞吐实测。它们不等于具备前沿基础模型的完整预训练预算。

人员、算力与交付节奏

未来两周的建议配置：一人完成 ESN 成果整合与逐项事实核对；一人负责主线数据、标签和完整历史基准；一人负责最强记忆基线和成本计量；第四人若有，负责模型与方法原型。只有两人时，由第二人顺序执行后两项，缩小实验范围。

先用 1–2 卡测吞吐、显存与基线，随后把 4–8 卡用于独立种子、预算点和第二模型的并行验证；不要先用全部资源做一个长训练。第 1 周交付可重跑的直接前人基线、来源独立的测试集和错误归因；第 2 周交付预算–错误曲线、配对证据与继续/改题判断。通过后再安排约 6–10 周完整实验，这个时长是工作量估计。

会议上，机制与可泛化资源规律更适合 ICML 叙事，视觉任务及真实场景证据更适合 CVPR/ICCV/ECCV 叙事。以 2026-11-05 为基准，ECCV 2026 已在 9 月举行，ECCV 按偶数年举办；ICML 2027 官网已确认会议时间，但 CFP 当时仍待公布。本报告不把推测的投稿日期当已发布截止日。
